Differentiator: Plagiarism / Similarity Check
Turnitin-style detection is the hardest part to replicate — its real moat is a huge private corpus of previously-submitted papers, not the algorithm. A realistic MVP combines two sources:
External API
 — call an existing API (Copyscape, Originality.ai, PlagiarismCheck.org) for web-wide matching
Internal index
 — build a growing internal index of your own users' submitted documents, fingerprinted and matched against each other, so repeat submissions get flagged honestly
Pipeline: upload → extract/OCR text → generate n-gram shingle fingerprints (MinHash/SimHash) → match against both sources → return a similarity score with highlighted matching passages, and add the new fingerprints to the internal index for future checks.

Lessons From iLovePDF's Play Store Reviews
Pulled directly from the live Android app's reviews (150 recent + 80 filtered to 1-star):
Billing trust
 — Trial billing charged immediately instead of after the stated free-trial period, with refunds often denied
Paywall timing
 — Users blocked from saving/exporting only after finishing their edits — widely called a bait-and-switch
Stability
 — Crashes on open, generic error messages, and a text-editing tool that frequently breaks
Missing feature
 — No in-app file search, despite being repeatedly requested
Privacy
 — Documents uploaded to the cloud without a clear in-app notice
